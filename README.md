## 🌟 四大核心互動模式

### 1. 🎮 【比序猜猜看 (PK 競猜大挑戰)】
精選 6 道國三生最常踩坑的真實案例（神仙打架、作文絕殺、+號逆轉、連續同校志願序陷阱、單科國文定生死、增額錄取傳奇）：
- 先看兩位考生的成績單與志願卡。
- 猜猜看誰會搶下目標學校的最後 1 個錄取名額！
- 點擊後啟動**「動態比序光速天梯掃描動畫」**，逐關對決，親眼看見是在哪一關分出勝負！
- 猜中伴隨音效與彩帶禮炮，並提供簡章法規深度解析。

### 2. 🧪 【對決沙盒模擬器 (雙人自由比序)】
- 自訂考生 A（代表自己）與考生 B（競爭對手）。
- 自由調整五科等級 (A++~C)、作文級分 (1~6)、志願序 (30/29/28分)、校序與志願順次、多元學習 27 分細項。
- 提供 5 大經典戰役一鍵載入（5A vs 4A1B、同積點+號對決、國文單科PK、同校跨科連續選填、平手增額）。
- 點擊「🚀 啟動電腦分發比序對決」，即時產出 13 關比序診斷報告書！

### 3. 🗺️ 【116 比序流程圖全景導覽 (互動學習圖)】
- 完整重現官方比序流程圖的 13 階結構。
- 點擊任何節點，右側立即展開詳細計算公式、法規條文與國三生必看考點。

### 4. 💡 【國三志願選填錦囊與秘笈】
- 破解常見升學迷思：連續選填同校不同科的免扣分神技、10個志願序同分群組策略、國文為何是中投區大魔王、作文 1 點定江山的真相等。

## 🚀 如何開啟使用？
本平台為**零依賴純前端單頁應用程式 (SPA)**：
1. **方式一 (最簡單)**：直接**雙擊 `開啟互動網頁.bat`** 或 **雙擊 `index.html`**，即可在 Chrome、Edge、Safari 或任何現代瀏覽器中立即體驗！
2. **方式二 (本機伺服器)**：在終端執行 `python start_server.py`，將自動開啟 `http://localhost:8080/index.html`。
